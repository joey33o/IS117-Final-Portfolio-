# Implementation Phases

This repo uses a small set of phase playbooks (instead of planning/active/complete sprint folders).

## How to use
- Read the specs in `project_management/specs/` to understand requirements.
- Follow the phase docs below to implement the specs with copy/paste-ready commands and code.
- Keep these phase docs minimal; update them as you complete work.

## Phases (run in order)
1. Phase 01 — Foundation: Next.js + Tailwind + Brutalist tokens
   - `phase-01-foundation-nextjs-tailwind-tokens.md`
2. Phase 02 — Content + Hero + Proof Block + Specs Table
   - `phase-02-content-hero-proof-specs.md`
3. Phase 03 — Accessibility + QA hardening
   - `phase-03-accessibility-and-qa.md`
4. Phase 04 — Static export + GitHub Pages deployment
   - `phase-04-static-export-and-github-pages.md`

## Spec coverage map
- Phase 01 → Specs 01 (foundation)
- Phase 02 → Specs 02, 04, 05 (content + hero + proof)
- Phase 03 → Specs 06, 07 (motion policy + accessibility)
- Phase 04 → Spec 08 (deployment)
