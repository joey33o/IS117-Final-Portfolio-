# Role

You are an expert web developer specializing in high-performance, Brutalist UI design and system architecture.

# Context: The Goal

I am building a single-project portfolio site that positions me as a "Hero" archetype—a dependable, high-capacity engineer who uses AI as an engine but maintains full human control. The audience is employers looking for a developer who understands how to use new technologies responsibly.

# The Brand & Aesthetic

- Archetype: Hero (Strong, reliable, authoritative, transparent).
- Aesthetic: Brutalist (Raw, "truth to materials," high contrast, heavy borders, strict grid, no "fluff" or decorative animations).
- Feel: Dependable, solid, engineered, functional.

# The Portfolio "Must-Dos"

1. Communicate the Hero archetype on the first read.
2. State a specific professional promise on the first screen: "AI-AUGMENTED. HUMAN-AUDITED. BUILT TO SCALE."
3. Since I am only featuring one project, the layout must be a "Single-Project Masterclass." It should be large, commanding, and the central focus.
4. Give the visitor a clear next step: A GitHub link as the primary Call to Action.
5. Feel intentionally made, structural, and "blueprinted."

# The "Proof" Framework (Single Project)

The project section must follow this specific logic:

- Block Title: Naming the problem/goal.
- The Artifact: A large, central visual (code snippet, system diagram, or screen).
- The Impact: Plain language on what changed.
- The Method Note (Broken into 3 sub-headers):
  1.  THE CHALLENGE
  2.  THE ARCHITECTURAL CHOICE
  3.  THE AUDIT (Crucial: Explain how I manually verified/fixed the AI's output).
- The Caption: Tying it back to my "Hero/Reliable" promise.
- The Call to Action: A button labeled "AUDIT MY CODE ON GITHUB."

# Technical Requirements

- Layout: Strict grid, 2px-3px solid black borders, heavy typography (Inter or System defaults), no rounded corners, no fade-in animations.
- The entire page should load instantly and feel like a technical manual or blueprint.
- Include a "Specs Table" for the project (e.g., Unit test coverage, performance, tech stack).

# Task

Please provide the foundational HTML/CSS to set up this single-project Hero portfolio. Ensure the design is aggressive, high-contrast, and emphasizes a "solid, engineered" feel.
